Hermes Agent

Personal AI agent setup by Rohit Swami.

What this app does: this OAuth client is used exclusively by my own personal instance of the Hermes Agent open-source framework to manage my own Google Calendar events and Tasks. It requests only:

  • calendar.events — create/edit my calendar events (reminders I schedule)
  • calendar.readonly — read my schedule
  • tasks — manage my task lists

No data is collected from anyone else. This app is not intended for public use.

Privacy policy: all data stays between my Google account and my private agent instance — nothing is stored, shared, or processed by any third party. Contact: privatestudent33@gmail.com
